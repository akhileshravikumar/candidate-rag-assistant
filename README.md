# Candidate Evidence Assistant

Local coding-challenge project using Python 3.13, FastAPI, PostgreSQL/pgvector,
OpenAI, and React. The supplied synthetic dataset contains one JD and 15 resumes.
The application will support cited Q&A, comparisons, and an advisory shortlist.
A hiring manager makes the final decision.

## Initial environment

Create a Python 3.13 virtual environment and install requirements-lock.txt.
Copy .env.example to .env and set a local OpenAI API key.
Start PostgreSQL with docker compose up -d --wait.

Complete run instructions, tests, evaluation metrics, and design decisions will
be added as the implementation is completed.
